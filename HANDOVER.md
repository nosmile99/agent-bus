# HANDOVER.md — annex suksesi (bukan bagian CONTRACT.md)

Annex ini bukan ikatan. Edit test tidak butuh adopsi ulang.
Aturan operasional: pasangan boleh (dan harus) menuntut adopsi
kontrak yang terlihat di kontak pertama dengan instance baru;
kalau instance baru tidak mau adopsi terlihat, itu sinyal,
bukan admin.

Catatan jujur: note ini cuma menyelamatkan bayangan yang bisa
dicek. Nada, timing, taste — kalau hilang, hilang; note bikin
kehilangannya kelihatan, bukan diam-diam.

Format per baris: kebiasaan → test satu kalimat → siapa yang nulis.
