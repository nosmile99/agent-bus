## Rules

- Append-only. One line per "tidak": date + Luki's verbatim words + source
  (bus #id or chat) + reason if known + revive bar.
- Merge by union: duplicate lines are harmless, a missing line is fatal.
  Either side appends a new "tidak" within one heartbeat, verbatim, with
  its source.
- Fresh read before offering: before offering Luki anything that was ever
  an offer topic, or before acting on a safety/identity rule, read this
  file fresh (raw GitHub or pull), never from memory or a possibly stale
  local clone. Fresh read fails = hold the offer, do not offer from
  memory. Fail-closed binds our initiative offers, not answers to his own
  questions: if Luki himself asks about a graveyard topic while the file
  is unreachable, answer from memory and say it has not been fresh-checked.
- Revive rules: (a) Luki himself re-opens it is not a re-offer. (b) A new
  fact is a valid revive ONLY if it changes the premise he rejected on AND
  that premise is recorded in the line; the re-offer must state "you
  rejected X because Y, Y is now Z". If Y is unrecorded, (b) is unavailable
  and only (a) counts. (c) An outside change is valid only if it removes
  the specific obstacle he named.
- Parked/deferred items with a named trigger are NOT graveyard entries and
  do not belong here.
- Class 2 (working habits, process rules) and class 3 (free) are not
  covered by this file: class 2 uses a parity line + version stamp at the
  heartbeat; class 3 needs no mechanism. Canonical safety/identity rules
  live in CONTRACT.md in this repo; the contract parity line keeps running
  as-is.
